02 — SAE & Projets

Travaux académiques

Quatre SAE menées à l'Université Sorbonne Paris 13 — du pentest offensif à la réponse à appel d'offre, en passant par le développement réseau et l'analyse de risques TPRM.

// SAE 303-CYB — CYBERSÉCURITÉ OFFENSIVE
↗
Découvrir le Pentesting
Mise en place d'un lab virtuel complet (Kali Linux, Metasploitable 2, Windows XP) en mode pont pour simuler des attaques réelles. Scan de vulnérabilités avec Nessus : 9 critiques, 7 élevées, 26 modérées détectées.

Metasploitable 2 : Exploitation VNC via mot de passe par défaut (CVSS 10.0), Bind Shell backdoor sur port 1524 (accès root immédiat), montage NFS sans restriction (lecture /etc/passwd), accès Tomcat Manager avec credentials par défaut.

Windows XP : Exploitation MS08-067 (SMB) via Metasploit → session Meterpreter avec droits SYSTEM. LLMNR/NBT-NS Poisoning via Responder → capture hash NTLMv1.

Pour chaque vulnérabilité : analyse, exploitation documentée, et mesures correctives proposées.
Kali Linux Metasploit Nessus Nmap VNC exploit MS08-067 Meterpreter Responder LLMNR Poisoning NFS VirtualBox
AVEC — HADDADI Kylian
// SAE 4.01 — SÉCURITÉ DÉFENSIVE
↗
Analyse TPRM — Sécuriser un SI
Rapport d'analyse de risques Third-Party Risk Management (TPRM) sur trois outils : Snort IDS, pfSense et KeePass. 14 risques identifiés (3 critiques, 9 élevés) selon la grille Impact × Probabilité. Mesures techniques de durcissement + clauses contractuelles opposables pour chaque risque.
TPRM Snort IDS pfSense KeePass ISO 27001 NIST CSF FIM / SIEM Zero Trust
AVEC — MILOUS Jalil
// SAE 3.02 — DÉVELOPPEMENT RÉSEAU
↗
Application de messagerie instantanée
Architecture client/serveur TCP complète. Serveur Python multi-threadé (un thread par client), protocole applicatif JSON avec préfixe de longueur pour éviter les messages tronqués. Frontend web via Flask, persistance SQLite, groupes jusqu'à 50 participants. Gestion des erreurs standardisée côté serveur.
Python TCP Sockets Flask SQLite Multi-threading JSON Git / Trello

// SAE — GESTION DE PROJET · APPEL D'OFFRE
↗
NEXUS Technologies — Réponse à l'appel d'offre · Ville de Valence
Simulation professionnelle complète : réponse à un appel d'offre de modernisation du SI municipal de la Ville de Valence (12 sites, 120 postes, infrastructure obsolète). Rôle de chef de projet IT.

Architecture proposée : cluster Dell PowerEdge R750, Hyper-V 2022 Failover Clustering, Fortinet FortiGate 600F, Veeam Backup Enterprise, segmentation VLAN, WiFi Ruckus R750 6. Plan de migration en 5 phases sur 8 mois, matrice RACI, analyse des risques, synthèse financière 265 000 € avec ROI 45% sur 3 ans.
